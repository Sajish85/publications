A source-linked catalogue of NVIDIA GPU Xid error codes with documented-action classification

Sajish Krishnan · Independent researcher · ORCID: 0009-0009-7561-9290
Published 2026-11-19 · DOI: 10.5281/zenodo.24362095 · Licence: CC BY 4.0

Abstract

NVIDIA drivers report GPU faults to the system log as numbered Xid events. The numbers and their meanings are published in several places that differ in coverage and, for 10 codes, in naming. This dataset joins four NVIDIA-published sources into one table with one row per Xid code: 186 codes, numbered 1 to 186. Each row carries the names used by the sources, the product-applicability flags and resolution buckets from the documentation catalogue, a short own-words summary, three classification fields (subsystem, derived severity, documented recovery action) with the stated basis for each value, and pointers to the source locations. Where the sources give no support, the field holds "not documented". The files are a CSV and a JSON file with identical content, a data dictionary, a source list, a classification guide and a QA report. The release does not include SXID (NVSwitch) codes, which none of the four sources lists.
