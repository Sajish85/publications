Abstract

Analysis code, exact input files, and generated outputs for the paper "Machine Class Is the Message" (Krishnan, 2026). The paper characterizes the KANVAS project's derived feature matrix (18,890 tasks, label Failed vs Terminated) from the Alibaba Cluster Trace GPU v2020. This archive contains the three analysis scripts (eda.py, stratified.py, charts.py), the input CSVs as downloaded from Hugging Face on 16 November 2026, the results JSONs the paper's numbers were taken from, and the four figures. All random splits use seed 42; re-running the scripts in the pinned environment (requirements.txt) regenerates the outputs. Licensing: the code in this archive is MIT-licensed; the data files are CC-BY-4.0 (KANVAS project release, derived from the Alibaba Cluster Trace GPU v2020); the record license is CC-BY-4.0. Also available at https://github.com/Sajish85/machine-class-is-the-message Version 1.1 (17 November 2026) adds the paper PDF (v1.1). The v1.1 paper corrects the description of the 'Terminated' status in Sections 3 and 8: the source trace documentation defines 'Terminated' as successful completion; v1.0 described it incorrectly. No data, analysis, or result is changed.
